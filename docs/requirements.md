# 要件定義書：割り勘精算アプリ「ワリカンスッキリ」

## 1. 背景・課題
旅行や飲み会で「Aさんがホテル代、Bさんがレンタカー代、Cさんが夕食代を払った」というように
**立て替えが複数人・複数回に分かれる**と、最後に「誰が誰にいくら払えば清算が終わるか」の計算が面倒になる。

- 電卓やスプレッドシートで計算すると時間がかかり、間違いやすい
- 送金の回数が多くなりがち（全員が全員に払う状態）
- 既存アプリはアカウント登録が必要だったり、広告が多かったりする

## 2. 誰の（ターゲット）
- 友人・家族・サークルなどで旅行や飲み会の**幹事をする人**（20〜40代、スマホでの利用が中心）
- ログインやインストールなしで、その場ですぐ使いたい人

## 3. 何を（解決すること）
「誰が・何に・いくら立て替えたか」を入力するだけで、
**最小限の送金回数で清算できる「誰 → 誰：いくら」のリスト**を自動で出す。

## 4. どう解決するか（機能要件）
| # | 機能 | 優先度 |
|---|------|--------|
| F1 | メンバーの追加・削除（名前のみ） | 必須 |
| F2 | 支払いの登録（内容・金額・払った人・対象メンバー） | 必須 |
| F3 | 一部のメンバーだけで割る支払いに対応（例：お酒を飲んだ人だけ） | 必須 |
| F4 | 一人あたりの収支（払った額 − 負担額）の表示 | 必須 |
| F5 | 最小限の送金回数に近い精算リストの表示 | 必須 |
| F6 | 入力内容をブラウザに自動保存（再読み込みしても消えない） | 必須 |
| F7 | 精算結果をテキストでコピー（LINE などに貼れる） | 必須 |
| F8 | URL で共有（入力内容を URL に埋め込み、開くと同じ状態を再現） | 推奨 |
| F9 | 支払いの削除 / 全リセット | 必須 |

## 5. 非機能要件
- **ログイン不要・サーバー不要**（データはブラウザ内のみ。個人情報を外部に送らない）
- スマホ幅（375px）で快適に操作できること
- 金額は日本円・整数で扱う。割り切れない端数は誤差 1 円以内に収め、合計が必ず一致すること
- 精算ロジックは単体テストで検証すること
- Vercel で静的サイトとして公開すること

## 6. 対象外（やらないこと）
- ユーザー登録・ログイン、複数端末でのリアルタイム同期
- 外貨・為替換算
- 実際の送金（PayPay などとの連携）

## 7. 成功の基準
- 4 人・5 件の支払いを 1 分以内に入力し、精算リストをコピーできる
- 精算リストどおりに送金すると、全員の収支が 0 円になる
